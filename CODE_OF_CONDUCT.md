# Code of Conduct

MkDoxy welcomes contributors with different backgrounds, identities and levels
of experience. Help make participation respectful, constructive and accessible.

## Expected behavior

- Discuss code and ideas respectfully, including when disagreeing.
- Give actionable feedback and make room for questions and learning.
- Respect people's time, privacy and boundaries.
- Take responsibility for mistakes and respond constructively to corrections.

Harassment, threats, discriminatory abuse, sexual harassment, publishing another
person's private information without permission, and repeated personal attacks
are not acceptable. These expectations apply to project issues, pull requests,
discussions and other spaces used for MkDoxy collaboration, including AI-assisted
contributions and automated comments.

## Reporting and moderation

Report concerns privately to the repository owner, Jakub Andrýsek, at
**email@kubaandrysek.cz**. Include relevant links and context without posting
private information publicly. Information from a report should be shared only
as needed to assess and address it.

The repository owner is responsible for moderation and may clarify expectations,
request changes, remove harmful content, or restrict participation according to
the circumstances. Participants are expected to follow reasonable moderation
requests. Enforcement is handled by a volunteer maintainer; no response deadline
is guaranteed.
