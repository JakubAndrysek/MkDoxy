# Paragraph title fixture

Owned C++ input exercises plain, bold, mixed, italic, code and untitled `@par`
sections, nested bold/italic markup and padded inline elements, plus standard
note, warning and see-also sections. Tests inspect real
Doxygen XML, generated Markdown and HTML. No Graphviz or extra dependencies are
needed. This continues the custom-title contribution from PR #143 by Chris Tallman.
